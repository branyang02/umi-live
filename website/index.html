Abstract

Handheld Universal Manipulation Interface (UMI) devices let human experts demonstrate tasks directly. Preparing these demonstrations for learning still requires consistent hardware, calibration, and data processing. We present UMI-Live, a bimanual hardware and software system for in-the-wild collection and robot learning. Each gripper integrates camera and LiDAR–inertial sensing, onboard compute, and power, without external tracking equipment or calibration of the collection environment.

A single button controls recording while an asynchronous pipeline performs parallel and batched reconstruction and publishes validated LeRobot datasets. We evaluate π0.5 and MolmoAct2 on placing six oranges in a bowl, with up to 10/10 and 8/10 successful trials, respectively. We release approximately 40 hours across three tasks and plan to release hardware designs, software, and reproduction guides at the project repository.

Using UMI-Live

UMI-Live is self-contained and designed for convenient, in-the-wild data collection. Attach the batteries, connect the power cables, and press one button to record. No external tracking infrastructure or calibration of the collection environment is required.

Automatic software processing

Keep collecting while completed recordings are processed in the background. Our server runs LiDAR decoding, trajectory reconstruction, and gripper estimation concurrently across hands and episodes, then assembles the results into training-ready datasets. Completed stages are tracked so interrupted processing can resume from available outputs.

The server checks synchronization evidence and corrects sensor timestamps before aligning the streams. LiDAR–inertial SLAM reconstructs each gripper’s motion, which is converted into a tool-center-point trajectory. ArUco detections estimate jaw opening, while the leader camera provides a common timeline for both wrist videos, poses, and gripper states.

Validated episodes combine synchronized wrist images, bimanual pose and gripper states, and task instructions in LeRobot format. The software can publish the dataset and raw-episode archive to Hugging Face, retaining the local dataset if publication fails. The full processing pipeline is available in our UMI-Live repository.

Experiments

Policy training and evaluation

We fine-tune π0.5 and MolmoAct2 on a shared representation of handheld UMI-Live demonstrations and robot teleoperation data. The policies use two wrist-camera images, gripper openings, and a task instruction, with no overhead-camera input. They predict coordinated action sequences for both arms: end-effector pose changes (delta EEF) relative to the pose at each policy query, together with absolute gripper openings. A remote policy server returns these sequences to a local client that controls the dual YAM arms.

We evaluate autonomous execution on a six-orange placement task, with randomized orange and bowl positions. π0.5 succeeds in 10/10 trials using a 90% UMI / 10% teleoperation training mixture. MolmoAct2 achieves 8/10 with a 75% / 25% mixture, compared with 0/10 for its released checkpoint without additional training.

Teleoperation setup

Our teleoperation setup pairs UMI-Live hardware with Vive trackers and base stations for live pose tracking instead of LiDAR. We optimize the system for low latency and high tracking accuracy, enabling precise teleoperation tasks such as lighting a match. We release the hardware configuration, setup instructions, and code in our teleoperation repository so others can reproduce the system.
